About This Plan

This plan follows Treehouse's official Front End Web Development track — a 41-hour curriculum — with one change: the two intermediate CSS courses have been removed to keep the plan achievable within two months.

It covers HTML, CSS, JavaScript, Git, and Bootstrap, requiring roughly 4 hours per week.

Two courses removed from the official track
  • CSS Flexbox Layout (1 hr 45 min) — Intermediate
  • CSS Grid Layout (1 hr 51 min) — Intermediate

If you're flying through the plan, Flexbox is the one to add back — it's very commonly used in real codebases including Canva's.

How to get the most out of this plan

The most important thing to know: don't just watch the videos. Watching someone write code and actually writing it yourself are completely different experiences — your fingers need to learn this too.

As each video shows something new, pause it and type it out yourself. Make it work. Then break it on purpose and see what happens. That moment of "oh, that's why" only comes from doing it, not watching it.

A simple habit that makes a huge difference
  • Keep a code file open alongside every video. Type out each example as it appears — even if you're just copying what's on screen.
  • Change something. Once an example works, tweak a value, rename something, try a variation. This is where real understanding happens.
  • If you're confused, rewind — not Google. The answer is almost always two minutes back in the video. Give it another watch before searching.

Challenge after Week 1

Build a simple fan page for your favourite game using only HTML — headings, a paragraph, an image, and some links. No CSS yet! Pick something you're into: FNAF, Jurassic Park, a favourite band, movie — whatever you like.

To get started, try one of these:

  • In the browser (easiest): Go to codesandbox.io, create a new "Static" sandbox, and edit the index.html file — your page appears live on the right.
  • On your computer: Download VS Code, create a file called index.html, write your HTML, and open it in your browser to see it.

What You'll Learn

  • HTML tags and how they wrap content
  • Headings, paragraphs, links, images, and lists
  • How a web page is structured (head vs body)
  • Your first look at CSS — how it connects to HTML

Challenge after Week 3

Take your Week 1 fan page and bring it to life with CSS — or build a brand new one. Try Minecraft or Grounded, or whatever game you're into right now.

Here are some ideas for using CSS colours to match the game's feel:

  • Minecraft: Use background-color: #2d5a1b for a grassy green, color: #6b4423 for dirt brown, and color: #5b8dd9 for a diamond blue — then set font-family: monospace for that pixelated blocky text feel.
  • Grounded: Go with deep jungle tones — background-color: #1b3a1f for the undergrowth, color: #8B4513 for earthy orange-brown, and a bright color: #c8e840 for that bug-eye neon yellow.
  • Any game: Open the game, look at the main menu colours, and try to copy that palette with CSS. Use background-color, color, and border to match the vibe — you'll be surprised how much difference three colours makes.
